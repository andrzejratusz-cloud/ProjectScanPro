# Project Scan Pro

Statyczna strona internetowa w języku polskim. HTML, CSS, JavaScript i ilustracja SVG znajdują się w pliku index.html. Fonty pobierane są z Google Fonts.

## Podgląd
Otwórz index.html w przeglądarce.

## GitHub Pages
1. Dodaj index.html do głównego katalogu repozytorium.
2. W Settings → Pages wybierz Deploy from a branch.
3. Wybierz gałąź main i katalog / (root), a następnie Save.

Dane kontaktowe firmy wymagają uzupełnienia. Pole opisu kopiuje tekst do schowka i nie wysyła wiadomości.
